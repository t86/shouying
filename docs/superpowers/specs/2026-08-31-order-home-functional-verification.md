# 点单首页：本轮功能闭环与验收

## 已实现的两项

### LOCAL-002：区域展开与选择

区域按钮超过当前宽度时出现固定“其它”入口，弹出当前可见的全部授权区域，同时提供“我的卡台”“全部”。选择后过滤卡台、同步区域统计、清除旧状态筛选并让选中区域可见；关闭不改选择。区域删除或权限收紧后，不继续使用旧选项。

对应源码仍为 `src/views/Order/newOrderCard.vue`；不是只配置 A/B 区，也不是借上下卡台翻页按钮切换区域。

### LOCAL-003：低消进度统计表

点单首页“更多功能 → 低消进度统计表”现在接到现有查询链路，不再弹“待接入”。

- 沿用 `POST /wo/get_seat_zy_csm_list`，不增加请求参数或请求体，使用当前点单会话。
- 对照实际导入的 `src/components/money/newDrawerMinDetail.vue`，保留12列及字段顺序：序号、区域、卡台名称、开台时间、订位人部门、订位人、最低消费、主营金额、差额、低消进度、清台时间、标签。
- 不重新计算金额、差额或进度；保持服务端提供的显示值。无数据、失败重试、关闭都可操作。
- 点单模式原版隐藏导出，本轮同样不增加导出按钮。收银模式的导出及其它报表继续由原任务负责。
- 界面双向滚动、纵向虚拟化；最多10000条，超限明确失败，不静默截断。复用已有较大响应预算的客户端，无新三方依赖。
- 会话对象、连接代次在请求前后核验。失去在线状态、进入安全模式或权限/区域范围变化时清空旧行。即使断开/恢复在同一帧发生，也观察原始连接流使旧数据失效，只能显式重新查询。

## 用户验收步骤（待确认）

1. 重新登录安卓版点单，点“其它”，选择原来右侧不可见的区域。核对卡台及底部统计，再回“我的卡台”和“全部”。
2. 使用与原 Web 相同的账号、系统和营业日，打开两边的低消进度统计表，比较行数、行序以及12列；没有数据时应均为空态。
3. 关闭统计表，应回到原卡台筛选位置；必要时模拟断线恢复，旧报表不能直接保留，重试才重新查询。
4. 这两项确认后更新子任务为“已确认”。TABLE-003、RPT-024等父任务还有其它系统/字段范围，不因子任务通过而自动完成。
