# 部门实时订台表层级行样式

## 目标

在“部门实时订台数”表中，清晰区分一级部门与二、三级部门，同时保留现有的部门缩进、合计行和区域开台表视觉规则。

## 设计

- 以报表接口部门名称的前导空格计算层级：无前导空格为一级，普通或全角前导空格为二级及以下。
- 一级部门行使用方案 A：浅蓝色背景、左侧蓝色强调线、加粗文字。
- 二级部门保持当前深色表格背景与现有缩进。
- 三级及以下部门保持现有缩进，并使用较弱的文字颜色。
- `id = 0` 的合计行继续使用橙色，不叠加部门层级样式。
- 区域开台总数表不应用这些部门层级样式。

## 实现边界

- 不改变部门列表数据、排序、接口调用或 Excel 导出。
- 在报表抽屉组件上增加仅用于部门行的层级 class；层级样式定义在现有报表 Less 文件。

## 验证

- 增加组件结构与样式回归测试：一级、二级、三级部门行分别带有对应 class；合计和区域行不带部门层级 class。
- 运行 `node --test tests/*.test.js`。
