# 门店后台五页真实报表配置（2026-09-20）

原先五页只有静态文字，没有读取/保存。现以当前Vue caller及`src/api/BMS/reportConfig`、`statistical`、`channelConfig`、`miniProgressConfig`为依据接入29个封闭操作，不允许页面自选任意接口地址。

## 已接入范围

- 鸡尾酒导出配置：部门树、独立父子选择、已配置禁选、按树顺序加入sheet、删除刷新。
- 销售商品统计设置：纠正旧误名“分类渠道统计设置”；两级分类、名称拼音、候选分页与全选、添加/删除，保留名称/分类/单价。
- 统计类别：新建、改名、营业类型、批量删除、排序，分类模式和商品模式的关联维护。
- 渠道类别：新建/编辑、包含渠道、归属锁定、删除和排序。
- 高毛利商品：服务员销售高毛利报表配置，候选分页、已配置禁选、批加/删除；不是“重点推荐”。菜单归属恢复为“小程序报表”。

所有读写共用org_mgr、在线状态、员工/终端对象身份及连接代际守卫。对话取消、错误提示、失败留稿及手机窄屏操作均纳入定向测试。没有对真实门店执行配置写入。

## 独立审查中的修正

- 非初始化统计商品请求原应init=2，不是0。UI模拟接口现在执行同一个request.body校验，避免只通过不校验字段的假接口。
- 补回统计商品的分类、商品类型、营业类型和重置按钮。
- 部门批加按原树顺序，不按点击顺序。
- 一级/二级分类ID是不同命名空间，不错误地排斥同号分类；未知或畸形数据不允许配置写入。
