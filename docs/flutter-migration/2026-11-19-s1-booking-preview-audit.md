## 五、预留管理页（需要产品拍板）

- **原 Web 版没有入口。** `/reserved` 路由和页面都在，`cardMachine.vue` 里也有 `goReserved()` 方法，但从仓库第一次提交起，模板里就没有任何地方调用它。线上用户只能手输地址进入，实际等于下线。
- 稿子在底部左侧加了醒目的"预留管理"入口卡，这是**新增功能**，不是还原。上线前要确认三件事：业务是否还要这个页面；后端接口（列表、删除、一键分配）是否仍然可用；咨客的操作习惯是否因此改变。
- 如果保留，页面要补齐原有内容：
  - 列：序号、订位人工号（稿子缺）
  - 其它预留的"日期"筛选和"明天 / 未来 7 天 / 全部"
  - 点客人姓名查看历史订单
  - 一键分配卡台的结果弹窗：成功 N 条、失败 N 条，以及说明"有意向卡台且意向卡台为空台才可以分配"

## 八、其他风险：公开仓库
