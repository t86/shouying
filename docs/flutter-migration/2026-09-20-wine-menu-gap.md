# 存酒菜单及安卓布局差异

## 原版依据

`ManagementSystem.vue` 的 `authority` 对 `system` 包含当前终端的直属菜单直接展示；`wineNavList.js` 的六组菜单均属于 `wine`。额外角色/模块用于跨系统扩展，并非存酒直属菜单的先决条件。

## 本轮修复

- Flutter 曾在所有菜单前强制要求角色资料完整，导致在线但缺少该资料时菜单全空。改为区分在线会话和角色资料：明确在线的直属菜单可见，扩展授权仍要求完整资料。
- Web/Android 传入真实连接状态。断线时卸载业务内容、关闭该页所属弹窗并限制接口调用；不支持离线业务。
- 小于720逻辑像素使用原生导航抽屉，保留六组菜单。桌面保留侧栏；标题省略避免溢出。
- 取酒待出库工具栏窄屏横向滚动，避免按钮溢出。

## 验证边界

权限和导航定向33项测试通过，含在线缺角色元数据、断线清理、390×844窄屏菜单切换、桌面导航及跨系统限制。最终业务包737项、Web/Android应用47项测试通过；静态分析0错误、0警告、134条既有info。边界检查及看板2项测试通过。
