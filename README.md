# managementsystem

## 项目安装
```
npm install
```

### 项目运行
```
开发环境  npm run serve
```

### 项目打包
```
npm run build
开发环境  npm run build-development
生产环境环境  npm run build-production
```

### url配置文件
```
--根目录下--
开发环境：.env.development
生产环境：.env.production
```

### 目录简要说明
```
接口文档目录 -----  /src/api
路由配置目录 -----  /src/router
请求配置目录 -----  /src/utils
页面组件目录 -----  /src/views
```
