## 📱 响应式设计规范

### 设备适配要求
本项目主要面向 **iPad 设备**，必须同时支持**横屏和竖屏**操作。

#### 目标设备
- **主设备**: iPad (1024x768, 768x1024)
- **兼容设备**: 其他平板设备
- **屏幕方向**: 横屏 + 竖屏双向支持

### UI 组件尺寸规范

#### 弹窗和对话框
- **宽度**: 最大 800px，小屏幕时 95%
- **高度**: 最大 90vh，超出时启用滚动
- **边距**: 顶部边距 ≤ 2vh

#### 表单控件
- **输入框高度**: 38-44px
- **按钮高度**: 38-42px  
- **字体大小**: 12-16px
- **内边距**: 15px (统一标准)

#### 交互元素
- **最小触摸目标**: 44x44px
- **按键间距**: 6-8px
- **动画时长**: 0.2-0.3s

### 响应式实现

#### 必须包含的媒体查询
```less
// 竖屏适配
@media (orientation: portrait) {
  .dialog { width: 95% !important; }
  .form-layout { flex-direction: column; }
}

// 小屏幕适配
@media (max-width: 900px) {
  .component { width: 95% !important; }
}
```

#### 开发检查清单
- [ ] iPad横屏显示正常
- [ ] iPad竖屏显示正常
- [ ] 弹窗不超出屏幕边界
- [ ] 按钮大小适合触摸操作
- [ ] 文字清晰可读
- [ ] 操作响应流畅

### 禁止事项
- ❌ 弹窗宽度超过 90%
- ❌ 按钮高度超过 50px
- ❌ 忽略竖屏适配
- ❌ 固定像素尺寸布局
- ❌ 过大的内边距 (>25px)

### 开发工具
项目根目录的 `.cursorrules` 文件包含了详细的开发规范，**必须严格遵循**。

**注意**: 本规范是为了确保系统在 iPad 设备上提供最佳用户体验，所有新功能和修改都必须符合以上要求。
